# UI components

This library keeps the components used by the current app, plus the transitive
components needed by their imports. It is not a copy of the entire registry.

## Current sources

- shadcn CLI 4.23.0, preserving the existing `base-lyra` configuration/theme.
- Base UI 1.9.0.
- `@shadcn/react` 0.3.1 for Message Scroller.
- Primitive source fetched using the official shadcn CLI; workspace imports and
  Lucide icons are transformed by the CLI.
- The five retained AI Elements wrappers follow the current shadcn migration
  patterns: conversation, message, tool, inline-citation and suggestion.

The wrappers preserve the names used by the app. Conversation uses Message
Scroller, messages use Message/Bubble, tools use Trace/Code Block, citations use
Base UI trigger timing and focusable buttons, and suggestions use Button.
The chat composer uses Input Group directly; it does not require the old
1,400-line prompt-input wrapper. Receipt actions are preserved.

## Adding a component later

For a standard component, from `packages/ui`:

```bash
bun --no-env-file x --no-install shadcn add COMPONENT_NAME
```

Review the source and dependency diff before committing. Do not install the
entire registry or blindly overwrite local changes. Follow existing workspace
imports and the Base UI variant, rather than mixing Radix-specific props in.

For an AI pattern, start from https://ui.shadcn.com/docs/ai-elements and add the
primitives it requires. The old elements.ai-sdk.dev registry is being retired;
its copied wrappers are not automatically updated by upgrading a package.

## Removed copies and dependencies

An import-graph inventory of all application source roots found five reachable
AI Elements wrapper files and 43 unused copies. The unused copies were removed,
along with 13 unreachable standard UI component files. Two unused highlighter
helpers generated by the registry were also omitted. Everything remains
recoverable from Git or the upstream registry.

Direct UI dependencies used only by removed files were removed: React Flow,
Rive, media-chrome, motion, cmdk, nanoid, react-jsx-parser, ansi-to-react,
tokenlens, the Radix controllable-state hook, and direct shiki. Streamdown and
its rendering plugins remain; their own transitive highlighting dependencies
are preserved. The obsolete use-stick-to-bottom dependency was replaced by
Message Scroller. Backend AI SDK/provider packages were not upgraded as part of
this UI refresh.

All retained UI source is included in the UI type check, including the five AI
Elements wrappers. No blanket AI Elements exclusion remains. Validation is type
checking and production bundling, followed by user-driven manual browser checks;
no paid model calls or automated browser suites are needed for this refresh.
